Standouts

  1. 1
    An audit of 216 public skills found most won’t reliably fire
    A scanner graded 216 Claude Code skills across 18 GitHub repositories against a pinned rubric and found 69% have a description that won’t reliably trigger — 40% outright unlikely to fire, 28% borderline — with only one skill in the whole sample passing every check cleanly. It surfaced the same week on a Hacker News Show, with every figure traceable to a pinned git-tree hash.
  2. 2
    Cloudflare open-sourced the skill behind its bug-hunting harness
    The skill runs a coding agent through six phases — reconnaissance, coverage-led hunting, adversarial validation, target-neutral reporting — on the rule that the agent who finds a bug is never the one who verifies it. It has reached 6,700 stars and 398 forks on a direct GitHub pull, and Cloudflare's own writeup says a single run finds only about half the bugs that repeated runs find in total.
  3. 3
    Tencent lets any shell-capable agent drive your real browser
    BrowserSkill borrows an already-logged-in Chrome or Edge tab for a task and hands it back afterward, so an agent can act on accounts you're signed into without a second set of test credentials. It has reached 5,100 stars and 354 forks on a direct GitHub pull, with installers for Cursor, Claude Code, Codex, OpenClaw, CodeBuddy, Pi, and Hermes Agent alike.
  4. 4
    A research workspace built entirely around coding agents
    OpenResearch gives Claude Code, Codex, OpenCode, or Cursor an isolated git worktree per research direction, an immutable archive of every experiment's commit, and an “autoresearch” loop that proposes and evaluates its own next experiment. It reached #1 on GitHub's daily trending page this week and sits at 4,800 stars and 300 forks on a direct pull.
  5. 5
    A skill marketplace where a person reviews every listing
    skillbay shows the same prompt answered with and without a skill before you buy it, curated by one person rather than scraped from GitHub, across categories from redlining contracts to AI video generation. It drew 25 points and 18 comments on its Hacker News launch thread this week, with new listings dated as recently as September 18.

Deep cuts

  1. 1
    A pattern library built from 100 real AGENTS.md files
    ossrules.md catalogs 1,214 skills and the AGENTS.md or CLAUDE.md files of the open-source projects that ship them — OpenClaw, n8n, Next.js, PyTorch among the 100 — tagged across 14 recurring techniques like “router files” and “hard prohibitions,” a searchable record of how real projects actually write agent instructions.
  2. 2
    A CLI that hides skills an agent doesn't need this session
    skillzero splits installed skills into hidden, bundled, or untouched, so a globally-installed skill's name and description stop eating context budget on unrelated tasks — a direct answer to the skill-hygiene problem Addy Osmani wrote about three weeks earlier.

Meta reads

  1. 1
    Skills beat agent-to-agent calls for lightweight delegation
    Microsoft rebuilt the same four-specialist demo two ways — agents calling agents, and one advisor loading MCP-delivered skills instead — and measured it: the skills path needed three model calls against six or seven, and ran faster in Microsoft's own reused-process tests (a mean of 6.3 seconds against 15.5), but was not cheaper, spending 22% more total tokens across the runs. The distinction isn't MCP versus agent-to-agent, Microsoft argues — it's delegating to another reasoner versus handing the current one a competence and letting it call the tools itself.
  2. 2
    Ten ways to get better results from AI, backed by research
    METR's 2025 randomized trial found experienced developers were 19% slower using AI on real tasks while believing they'd been 20% faster, and the essay builds ten practical fixes from there — curate context instead of stuffing it, since Chroma found all 18 tested models got less reliable as input grew, and keep a tool set under about twenty options, because choices get noticeably worse past that in the author's own use. A separate 1,150-person survey put the cost of unchecked AI output, now nicknamed “workslop,” at roughly $186 per employee per month.
  3. 3
    How Skills became MCP's lightweight sibling
    MCP started in July 2024 as one Anthropic engineer's fix for copying answers out of Claude by hand, moved to open governance under the Linux Foundation's new Agentic AI Foundation in December 2025, and by this July its two largest SDKs were pulling more than 470 million downloads in 30 days — a history that ends by noting Skills exist specifically because MCP connections got too heavy for everyday, repeated instructions.
